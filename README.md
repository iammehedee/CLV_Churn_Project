# CLV_Churn_Project
E-commerce ML project: XGBoost models for customer churn prediction and CLV forecasting. Built on retail transaction data with extended RFM features, time-based validation and hyperparameter tuning. Identifies key customer behavioural patterns for retention and marketing decisions.
